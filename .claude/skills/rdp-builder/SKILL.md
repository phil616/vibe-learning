# RDP Builder

读取 `.res.md` 或 `.res/` 资源文件，生成轻量的 `.rdp.md` 学习路线图。

**核心原则：rdp 是索引，不是内容库。**
知识本身住在 res，rdp 只存放节点结构、引用链接、掌握检查点和学习状态。
这样 rdp 文件始终保持轻量，OpenCode 读取时不会因内容过多而浪费 context。

---

## 第一步：读取 res 文件

**判断 res 类型：**

```
如果存在 科目名.res.md         → 读取单文件，提取所有二级标题（##）作为知识块列表
如果存在 科目名.res/index.md   → 读取 index.md 的文件列表，每个章节文件 = 一个候选节点
如果两者都不存在               → 告知用户先使用 res-builder skill 整理资料
```

读取后，列出识别到的知识块/章节，告知用户：

```
从 [文件名] 中识别到以下 N 个知识块，我将据此生成学习路线图节点：

1. [知识块名称] — [一句话摘要]
2. ...

是否需要调整节点顺序、合并或拆分？确认后生成完整 rdp 文件。
```

若用户说"直接生成"，跳过确认。

---

## 第二步：生成 rdp 文件

文件名：`科目名.rdp.md`（与 res 文件使用相同的科目名前缀）

### 文件头格式

```markdown
---
subject: Python 语言学习
type: rdp
created: YYYY-MM-DD
updated: YYYY-MM-DD
res: Python学习.res.md          # 或 Python学习.res/
progress: 0/7
---

# Python 语言学习·路线图

> 创建时间：YYYY-MM-DD | 整体进度：0/7 节点
> 资源文件：[Python学习.res.md](./Python学习.res.md)
```

### 节点格式（核心）

每个节点严格遵循以下结构，**CONTENT 字段只放引用链接，不放内容正文**：

```markdown
## N. 节点名称

### N.0 PREREQUISITES
[前置依赖，第一个节点写"无"]

### N.1 CONTENT
> 原始内容见资源文件：
> - 单文件：[Python学习.res.md § 1. Python语言介绍](./Python学习.res.md#1-python语言介绍)
> - 目录：[01-语言介绍.md](./Python学习.res/01-语言介绍.md)
>
> 核心主题：Python历史、设计哲学、GIL、适用场景

### N.2 COVERAGE
- [ ] [可验证的掌握检查点，行为动词开头]
- [ ] ...

### N.3 STATUS
- ❌ 尚未开始学习本节点

### N.4 LOGS
（暂无记录）
```

**CONTENT 字段写什么：**
- 指向 res 文件对应章节的 Markdown 链接（相对路径）
- 用 1-2 行的"核心主题"描述该节点涵盖哪些内容（方便 AI 快速定位）
- 禁止复制 res 中的知识正文到 rdp

---

## 链接格式规范

### 单文件 res 的锚点链接

Markdown 标题自动生成锚点，规则：全部小写、空格变连字符、删除特殊字符：

```markdown
[Python学习.res.md § 2. 基础数据类型](./Python学习.res.md#2-基础数据类型)
```

中文标题的锚点：直接用中文，GitHub 和大多数渲染器支持：

```markdown
[查看原文](./Python学习.res.md#2-基础数据类型)
```

### 目录 res 的文件链接

```markdown
[02-基础语法.md](./Python学习.res/02-基础语法.md)
```

若一个 rdp 节点对应多个 res 章节文件（如"综合实践"节点引用多个文件）：

```markdown
### N.1 CONTENT
> 原始内容见资源文件：
> - [04-函数.md](./Python学习.res/04-函数.md) — 函数定义、参数、作用域
> - [05-面向对象.md](./Python学习.res/05-面向对象.md) — class、继承、魔术方法
>
> 核心主题：函数与面向对象的综合应用
```

## COVERAGE 生成规范

从 res 文件的"核心要点"和"关键术语"中提取，转化为可验证的检查点。

**转化规则：**

| res 中的"核心要点" | 转化为 COVERAGE 条目 |
|-------------------|---------------------|
| Python 是解释型语言 | `[ ] 能解释"解释型语言"与"编译型语言"的核心区别` |
| GIL 限制多线程 | `[ ] 能解释 GIL 对多线程程序的实际影响，并说出绕过它的方式` |
| 字符串不可变 | `[ ] 能用代码演示字符串不可变性，并解释其内存含义` |
| f-string 格式化 | `[ ] 不查资料能写出带格式控制的 f-string（如保留两位小数）` |

**行为动词层次（从低到高）：**
- 记忆层：能说出、能列举、能背出
- 理解层：能解释、能描述、能用自己的话复述
- 应用层：能写出、能实现、能不查资料完成
- 分析层：能分析、能判断原因、能诊断问题
- 综合层：能设计、能独立完成、能对比方案

每个节点 4-7 条 COVERAGE，覆盖不同层次。

## 节点粒度决策

### res 知识块 → rdp 节点的映射关系

```
1 个知识块 → 1 个节点    （默认，最常见）
2-3 个相关知识块 → 1 个节点  （知识块较小且强相关时合并）
1 个大知识块 → 2 个节点    （知识块过大、COVERAGE 超过 8 条时拆分）
```

**合并信号：** 两个知识块的 COVERAGE 合计不超过 6 条，且存在强依赖关系
**拆分信号：** 单个知识块对应 COVERAGE 超过 8 条，或包含明显独立的两个子主题

### 依赖链设计原则

- 线性依赖链为主（避免复杂的多叉依赖）
- 强依赖（必须先完成）：`STATUS 需全部 ✅`
- 弱依赖（建议但非必须）：`（建议完成）`
- 可选扩展节点在标题后加 `[可选]`

## 完成后输出

生成文件后，输出摘要：

```
已生成：Python学习.rdp.md
共 N 个节点，关联资源文件：Python学习.res.md（或 Python学习.res/）
文件大小：约 X 行（不含原始知识内容）

目录结构：
  Python学习.res.md       ← 原始知识内容（约 NNN 行）
  Python学习.rdp.md       ← 路线图索引（约 NN 行）← 刚生成

使用说明：
- OpenCode 读取 rdp 了解学习进度和节点结构
- 需要查看具体知识内容时，跟随 CONTENT 中的链接打开对应 res 文件
- 学习状态更新写入 rdp 的 STATUS 和 LOGS 字段
```

详细格式示例和完整 rdp 样本见 `references/rdp-examples.md`
